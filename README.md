# Website-demo melhorado — Desfrute

Conceito não oficial preparado para apresentação comercial pela Atlas Digital.

## Como abrir

1. Extraia todo o conteúdo do ficheiro ZIP.
2. Mantenha `index.html`, `style.css`, `script.js` e a pasta `assets` juntos.
3. Abra `index.html` num navegador moderno.

Para uma pré-visualização mais fiel, pode também servir a pasta com um servidor local simples.

## Informação que deve ser confirmada pelo restaurante

- Carta completa e preços actuais.
- Disponibilidade diária dos pratos.
- Horário oficial actualizado.
- Utilização do telefone como WhatsApp.
- Texto institucional e história oficial da marca.
- Autorização final para uso das fotografias e do logótipo numa versão publicada.

Os preços foram apresentados como “Sob consulta” porque nenhuma fonte pública fiável expôs uma carta actual completa. Esta decisão evita inventar valores ou apresentar preços desactualizados.
